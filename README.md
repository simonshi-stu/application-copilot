# Application Copilot

面向不同求职者的本地优先申请准备工作台（开发中）：整理简历与公司清单、审核候选信息、原样复制确认文本。不绑定特定用户、公司或模型；不代登录、不代最终提交。

## 下一版本目标：准确性修复＋轻量工作台

保留原生 JavaScript 和已有简历解析能力，参考 [Tabler](https://github.com/tabler/tabler) 的信息布局，改为「公司列表＋当前公司详情」，不进行 React／Next.js 迁移。

- 先修复无资料也显示可复用、冲突内推码默认选第一项、纯公司名／纯链接列表拆分的问题。
- 区分草稿、待核实与本人确认；自动保存草稿不等于确认，更不等于官网绑定或投递成功。
- 资料卡区分已确认可复用、已识别待确认、待补充、来源待核实。行业模板仅供提示，不能把可能字段冒充网站必填项。
- 桌面使用紧凑表格＋详情区，移动端单列切换；保留简历段落库、原文来源及本地导入导出。
- 先给用户可试用页面，只补关键问题的小量回归；暂不增加云账号、计费、模型 API、真实网站自动填表或多 Agent 编排。

**这些是下一版本目标，尚未实现。** 架构和文件边界见 [ARCHITECTURE.md](docs/ARCHITECTURE.md)。

## 快速试用（MVP demo）

无需安装依赖，Node.js 22+：

```text
npm run serve
```

1. 打开 `http://127.0.0.1:4173/extension/editor.html`（默认进入「公司与清单」，左侧导航可切换「简历与段落」）
2. 粘贴公司 / 内推信息（编号、【】标题、纯名单、链接列表均可），点击「解析并生成草稿」
3. 在列表中点选公司：核对公司名、行业、链接与内推候选；改动自动保存（侧栏底部显示保存时间）

也可以作为浏览器扩展加载：Chrome / Edge 扩展管理页 → 开发者模式 → 加载 `extension` 目录，点击扩展图标打开。

示例粘贴（全部为虚构数据，可直接测试）：

## 功能细节

### 公司与清单导入（MVP）

- **界面**：深色左侧导航＋统计看板（全部／待核对／已确认／有问题，可点击筛选）＋列表＋详情；移动端列表／详情切换；详情含流程步骤条与「下一步」引导；草稿自动保存状态显示在侧栏。
- **完整流程**：我的资料（新增/导入并逐项确认）→ 粘贴导入公司 → 核对/选内推/补充逐公司问答 → 标记人工核对 → 复制送审单 → 本人提交后在详情里更新「进度」。
- **当前输入**：支持 emoji 编号、【】标题、空行分隔的纯公司名列表、无编号链接列表、公司名+链接组合；同一标题下的多链接保持同一条。复杂表格仍按纯文本解析。
- **自动识别**：公司名、链接（含短链）、内推码（`recommendCode=` 参数与文字码）、渠道提示（大使/员工/链接自带）、批次、截止日期。
- **内推码**：候选全部保留，冲突时选定值留空，必须由你在详情中手动选择（或选“本次不用内推”）；旧版曾自动填入的值只作提示。链接携带与自动识别都不等于官网已绑定。
- **行业建议**：本地规则＋小型公司名单给出建议与判断依据，可手动修改并本地记忆；不再显示未校准的百分比。企业性质、岗位方向是独立字段，未知保持未知。
- **信息卡**：分「已确认可复用／已识别待确认／待本人补充／需官网核实」，另有折叠的“部分单位可能要求”提示（不会提前收集敏感信息）；只有段落库中已确认的段落计入可复用。
- **数据**：本地保存；JSON 导出 / 导入（导入会重置确认与绑定标记）；重复条目（同公司 + 同链接）自动跳过。草稿自动保存与“标记为已人工核对”分开。

### 段落库

导入简历文字 → 自动识别区域与经历 → 你调整、分类、逐块确认 → 填写时原文复制。项目简述／职责可先生成带来源的候选，确认后才可使用；修改即取消确认，超长不自动截断。

### 本地简历解析

本地 DOCX / TXT / MD / 文本导入：识别个人信息、教育、实习（公司/地点/岗位/日期与正文分离）、项目、技能、语言与个人评价；缺失字段保持空白，项目岗位不默认"独立开发"。PDF 请粘贴已提取文本。

## 隐私与边界

- 全部本地运行：页面不发起网络请求，无遥测，无账号。
- 不代登录、不代验证码、不代最终提交；填写只使用本人确认文本。
- 本仓库只包含代码与虚构测试数据，**没有任何真实简历、内推链接或密钥**。

## 开发与测试

```text
npm test          # 轻量冒烟测试：段落库 / 简历解析 / DOCX / 公司解析 / 类型识别 / 信息卡
```

测试数据全为虚构样例。项目内 `private/` 保存私有资料和交接规划，`artifacts/` 保存截图及生成数据，`.cache/` 保存主动配置的项目缓存，均不提交。当前运行数据仍由浏览器存储管理，不会自动写入项目目录；用户可手动导出到 `private/`。直接落盘的本地服务属于后续独立任务。
