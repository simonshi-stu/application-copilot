# Application Copilot

本地求职申请准备助手。先把用户确认的简历段落固定下来，再受控填写；不靠招聘网站解析简历，不让模型重写经历，不代最终提交。

## 项目目标与完整流程

目标不是自由操作浏览器的自动海投，而是把重复填表交给程序，把岗位理解和异常判断交给模型，把事实确认、登录及最终提交留给本人。

```text
一次性准备：简历文字简单拆分 → 本人调整格式、区分内容与职责 → 确认段落及材料版本

单家公司：
官方页面／本人登录
  → 查历史投递，避免重复申请
  → 核实毕业窗口、海外认证规则及真实志愿额度
  → 根据当前 JD、本人经历和偏好推荐志愿顺序
  → 匹配网页字段，选择确认事实与原文段落
  → 批量填写，按要求上传简历和照片
  → 读回比对、保存状态核验、汇总缺失和风险
  → 停在最终提交前，由本人检查并提交
  → 只读核验投递结果，记录后推进同公司下一岗位／下一家公司
```

**以上是目标流程，不代表当前版本已全部实现。** 当前只有下文的离线段落库可用；公司核查、岗位排序、网站自动填写和模型接入仍待开发。

## 目标架构与模块分工

| 模块 | 责任 | 当前状态 |
|---|---|---|
| 本地段落库 | 用户调整、分类、逐块确认，原文复制 | 已实现基础版 |
| 事实与材料库 | 确认事实、来源、冲突、简历与照片版本 | 待开发 |
| 公司与申请记录 | 主体／批次／岗位识别，历史去重和状态区分 | 待开发 |
| 招聘规则与岗位匹配 | 官方资格、志愿额度、JD 证据与优先级 | 待开发 |
| 网站适配器 | 稳定定位、批量填写、附件上传和读回比对 | 待开发 |
| 工作流与人机协作 | 中断恢复、页面单写入者、本人审核及结果核验 | 待开发 |

计划采用浏览器扩展＋本地服务，先适配一个招聘平台，再扩展。模型只理解页面、选择已确认资料、判断岗位匹配和解释异常；程序执行确定字段填入和校验。不让模型逐字段反复决策，也不让它生成新的实习或项目文案。

技术接入按实际需要推进，以下尚未实现：

- **LangChain**：模型接口、结构化 JD／字段映射输出、受限检索与工具封装，不负责改写简历段落。
- **LangGraph**：显式状态、条件分支、持久化和人工中断；恢复后仍需重新检查招聘网页。
- **RAG**：按来源、有效状态、公司／批次检索相关经历证据和招聘规则。固定事实、附件版本、申请状态优先精确查询，不逐字段做向量检索。
- **浏览器执行层**：扩展站点适配器为主，必要时接本地 Playwright；填写模型不获得无限制点击、任意脚本或最终提交权限。

## 不可变更的工作边界

- 不用招聘网站解析简历来提取填写资料；附件上传单独管理，强制解析时先识别覆盖风险。
- 实习／项目文字只用本人确认段落，保留原文及空行，不自动重写、翻译、压缩或截断；缺职责段落或超限时请本人调整。
- 地点、岗位、实习内容、项目内容和本人职责分别映射，不能按空输入框顺序猜测。
- 资格和额度未知就标未知，不以系统允许填写或多选意向推断符合资格或可多次投递。
- 不代登录、验证码或最终提交，不撤回、删除或重复申请；本人审核通过也不产生代提交权限。
- 页面已填、草稿已保存、本人报告已提交和官网核验已提交分开记录。真实资料不进 Git，外部模型接收资料需要另行授权和最小化。

## 当前可用：离线段落库

1. 在 Chrome / Edge 扩展管理页开启开发者模式，选择「加载已解压的扩展程序」，加载本目录的 `extension` 文件夹。
2. 点击扩展图标，打开段落库编辑器；也可用本地静态服务器打开编辑器测试。
3. 粘贴自己从简历复制的文本，或导入 TXT / Markdown。按空行拆分只是草稿，不识别或推断本人贡献。
4. 手动调整段落，标明所属经历及栏目；项目内容和项目职责分别建立段落。需要保留多段时，可在同一块内编辑并留空行。
5. 每块单独勾选确认并保存，再点击复制。任何修改都会取消该块确认；复制严格使用确认文本，不压缩、不润色、不截断。
6. 若网站有限字数，可先输入上限。超限时拒绝复制，请用户返回编辑，不自动删改。该检查按浏览器 UTF-16 长度计算，实际网站可能另有计数规则。

复制保留正文、顺序和空行。Windows 系统剪贴板可能将 LF 转成 CRLF；网页文本框粘贴后通常恢复为 LF，核验只允许这种换行编码归一化，不允许改动文字或段落。请只打开一个编辑器页面整理资料，避免不同标签同时编辑产生覆盖。

资料仅保存于当前浏览器本地存储（不加密），不上传服务器，也不读取招聘页面。公用电脑不建议保存敏感资料；清空按钮删除本扩展的段落库，但不清除系统剪贴板。本扩展无遥测，无模型调用，无站点权限。原始粘贴文本仅在当前页面内存中，不自动保存；请不要粘贴密码、验证码、身份证等不必要的信息。

**当前不是完整自动填表插件。** 尚未实现 PDF / DOCX 解析、岗位检索、网站字段映射、自动照片上传、申请状态核验或模型调用。当前版本专门实现「简单拆分 → 本人调整 → 本人确认 → 原文复制」。

## 开发与测试

无需安装第三方依赖，Node.js 22+：

```text
npm test
npm run serve
```

静态测试页：`http://127.0.0.1:4173/extension/editor.html`。普通网页运行时使用浏览器 localStorage，与扩展存储相互隔离。
