# Application Copilot

一个本地优先的求职投递小工具：把简历和公司信息整理成“照着填”的清单，少重复、少填错。

## 1. 这是做什么的？

校招投递最烦的不是投一家，而是同一套信息在几十个网站反复填写：

- 网站解析简历经常串行、丢数字，把职责写成了项目描述；
- 每个网站字段顺序不一样，填到一半忘了自己填过什么；
- 投过哪家、进行到哪一步、内推码有没有绑定，过几天就记不清。

这个工具不替你投递，它只做三件事：

1. 把简历拆成“资料”和“段落”，由你确认后才算数；
2. 把公司清单、内推码、链接和公司问题整理成卡片；
3. 用确认过的内容生成“照着填”的清单，供你复制粘贴，并在提交前检查遗漏。

数据只保存在你自己的浏览器里，不上传服务器。

## 2. 使用场景和流程

适合应届生、实习生，以及需要重复填写网申的人。

1. 导入简历（DOCX 或粘贴文字），自动拆成教育、实习、项目等；
2. 到「我的资料」逐项确认（没确认的内容不会进入填写清单）；
3. 粘贴公司清单或内推信息（群里复制的一大段也能识别）；
4. 点开一家公司：核对信息、选内推码、补充这家公司才会问的问题；
5. 打开「照着填」：逐项复制到官网表单，填一项勾一项；
6. 点「检查一遍」（可选再让模型检查），复制或下载清单；
7. 自己提交，然后回来更新进度（待准备 → 核对中 → 待提交 → 已提交 → 已核验）。

登录、验证码和最终提交始终由你本人完成。

## 3. 现在做到哪一步了？

已经能用：

- **简历**：本地导入 DOCX/文本，区域解析，段落逐块确认，原文复制；
- **资料**：字段来源（手动/简历导入）、逐项确认、导出；
- **公司**：粘贴解析（编号、标题、纯名单、链接列表均可）、行业建议、内推码候选、逐公司问答；
- **填写**：照着填清单、进度与时间线、备注和申请号、本地自检、清单复制与下载、可选的 AI 检查；
- **MCP**：本地工具服务（解析、信息卡、清单、自检）。

还没做：

- 直接在招聘网站自动填表（需要站点权限和真实页面测试）；
- 投递额度台账、申请级去重；
- 更深一层的视觉和品牌打磨。

## 4. 怎么用？

### 在线试用

<https://simonshi-stu.github.io/application-copilot/>

### 本地运行

需要 Node.js 22+：

```text
npm run serve
```

打开 <http://127.0.0.1:4173/extension/editor.html>。

### 作为浏览器插件

Chrome / Edge 打开 `chrome://extensions` → 开启开发者模式 → 加载已解压的扩展程序 → 选择 `extension` 文件夹。

### 可选：MCP

运行 `npm run mcp`，客户端配置见 [docs/MCP.md](docs/MCP.md)。

### 使用提醒

- 数据保存在浏览器本地；换电脑或清理缓存前请先导出。
- AI 检查需要你自己的模型 Key，只存本机；线上页面可能受 CORS 限制。
- 不代登录、不代验证码、不代提交。使用前请阅读 [使用声明](docs/USAGE.md)。
- 部署方式见 [docs/DEPLOY.md](docs/DEPLOY.md)。
