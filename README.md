# Application Copilot

本地优先的求职申请准备平台（开发中）：解析简历与公司清单、识别公司类型、生成待补充信息卡；填写使用本人确认的原文复制。所有数据只保存在本机——不代登录、不代提交、不上传。

## 快速试用（MVP demo）

无需安装依赖，Node.js 22+：

```text
npm run serve
```

1. 打开 `http://127.0.0.1:4173/extension/editor.html`
2. 切到「公司与清单」标签
3. 粘贴任意格式的公司 / 内推信息，点击「解析并生成信息卡」
4. 核对公司名、类型、链接、内推码；改动自动保存在本机

也可以作为浏览器扩展加载：Chrome / Edge 扩展管理页 → 开发者模式 → 加载 `extension` 目录，点击扩展图标打开。

## 功能细节

### 公司与清单导入（MVP）

- **任意格式**：群消息、文档表格、链接列表；emoji 编号、【】标题、短链都能拆。
- **自动识别**：公司名、链接（含短链）、内推码（`recommendCode=` 参数与文字码）、渠道提示（大使/员工/链接自带）、批次、截止日期。
- **容错**：没有内推码照常建档；**多个不同内推码冲突保留双候选**，标注待核实，不自动选定。
- **公司类型**：本地规则 + 小型知名公司名单自动预选，显示置信度与依据；可手动修改，修改会被记住（仅本机）。
- **信息卡**：按类型生成「需你补充 / 将直接复用 / 需官网核实」三类字段（如车企问驾照，银行问征信类声明）。
- **数据**：本地保存；JSON 导出 / 导入；重复条目（同公司 + 同链接）自动跳过。

### 段落库

导入简历文字 → 自动识别区域与经历 → 你调整、分类、逐块确认 → 填写时原文复制。项目简述／职责可先生成带来源的候选，确认后才可使用；修改即取消确认，超长不自动截断。

### 本地简历解析

本地 DOCX / TXT / MD / 文本导入：识别个人信息、教育、实习（公司/地点/岗位/日期与正文分离）、项目、技能、语言与个人评价；缺失字段保持空白，项目岗位不默认"独立开发"。PDF 请粘贴已提取文本。

## 隐私与边界

- 全部本地运行：页面不发起网络请求，无遥测，无账号。
- 不代登录、不代验证码、不代最终提交；填写只使用本人确认文本。
- 本仓库只包含代码与虚构测试数据，**没有任何真实简历、内推链接或密钥**。
