# 在 OpenChamber 里使用

Application Copilot 的目标入口是 OpenChamber 工作插件，不是让你每天手动启动一个预览网站。任务池、资料、岗位选择和问题处理在插件里完成；招聘官网的登录、验证码和最终提交仍由你操作。

## 三种入口不要混淆

| 入口 | 适合做什么 | 不代表什么 |
|---|---|---|
| OpenChamber 插件 | 内嵌任务池与持久化工作流；具体执行能力以当前插件版本为准 | 面板能打开，不等于所有招聘网站都能自动填 |
| 原有网页／Chrome 扩展 | 整理简历、确认段落、生成复制清单 | 打开 GitHub Pages 不会启动插件服务 |
| 本地 stdio MCP | 把解析与清单函数提供给支持 MCP 的客户端 | 当前已有 MCP 工具不会自己读取网页登录态或提交申请 |

## 安装与授权

在支持扩展和宿主管理服务的 OpenChamber web／desktop 中，打开“设置 → Extensions”，添加插件文件夹或白名单 ZIP，再由你审核和批准权限。正式包须包含扩展 manifest、已构建面板、服务代码、运行所需模块和许可证，不能只复制一个 HTML 文件。

插件服务由 OpenChamber 按需启动。它内部仍是本地进程，但不需要你另外打开终端运行预览服务器。服务具有当前系统用户权限，安装时请阅读权限说明；面板不会得到服务认证凭据，也不提供任意文件读写或执行命令入口。

如果版本太旧、权限未批准、浏览器或模型未配置，插件应显示具体原因，不把功能降级伪装成成功。VS Code 和移动端不作为当前宿主能力承诺。实际最低版本、构建命令和可安装包路径以仓库根 manifest 与交付验证结果为准。

## 日常使用

1. 在当前项目中整理自己的资料并逐项确认；家庭资料按需填写，不要求预先交全。
2. 添加公司链接与可选内推码，启动限定范围的队列。
3. 按提示完成登录，选择有官方来源的岗位并排好顺序。
4. 在已接入且经过验证的执行能力范围内处理填写与复核；不支持的控件和缺失信息进入问题汇总。
5. 集中处理问题。你实际提交后记录岗位结果；本公司所选岗位结束后，队列再推进下一家。

流程和进度由程序及本地记录维持，不靠聊天上下文。关闭问题弹窗不会解决问题，会话结束也不会把岗位自动标成已投递。

## 资料在哪里

正式资料和任务记录应位于当前项目 `private/` 的明确子目录，具体路径由安装版本显示。旧网页的浏览器存储不会自动迁移或清空；迁移前请自行导出备份并审核导入内容。

真实姓名、简历、父母与家庭信息、项目内容、投递记录、附件、网页快照和密钥不得放进 GitHub 或分发包。仓库中的测试只用虚构数据。宿主安装副本、缓存及宿主凭据有其自管位置；连接远程 OpenChamber 时，它不是你的本机，不能笼统称全部资料仅留在本地。

使用云模型需另外授权必要资料的发送。检索、填写和独立 review 的模型由你选择，开发本插件所用模型不会自动变成业务账号。未配置模型或没有真实页面读回时，不能声称已经自动完成网站 review。

## 首个平台

用户选择 Moka 作为优先适配对象。原生文本框、下拉与自定义控件的支持必须分别验证；一个虚构表单通过，不等于所有公司、招聘批次及所有 Moka 页面已经兼容。没有具体官网与实际回归结果时，不作完整自动网申承诺。

受控驱动使用独立 Chrome／Edge 窗口，通过 CDP pipe 连接，不开放通用浏览器调试端口，也不读取日常浏览器 profile。其专用 profile 位于当前项目 `.cache/moka-browser/<browser>-<instanceId>/`，其中可能包含登录状态，请勿上传或打包。它不等于 OpenChamber 内嵌浏览器；宿主浏览器及旧网页的缓存仍由各自环境管理。

## 本轮验证到哪里

- 正在运行的 Windows OpenChamber 程序文件版本为 **2.3.2**；插件固定使用 SDK **2.3.2**，最低版本声明为 `>=2.3.2`。这是版本与接口对齐，不是所有后续版本的兼容保证。
- 面板和单文件 ESM 服务已构建，白名单 ZIP 解包后的 `/health` 已验证：无认证或错误认证返回 401，正确认证返回 200。
- 测试宿主桥接真实服务、真实 SDK 面板，使用虚构项目验证入队、本人登录回执、岗位选择、两岗位结束才推进下一家公司、问题回答与显式解决、跨项目草稿隔离和手机布局。测试桥不是正式宿主。
- 本机 Chrome 对被拦截的虚构表单完成观察、填写和读回；不连接真实招聘网站，不使用真实求职资料。
- **实际 OpenChamber 2.3.2 已完成安装联调，并用虚构 `example.invalid` 数据验证了权限、入队和关闭重开持久化；仍未验证真实 Moka 官网或真实模型供应商。** 不把以上测试写成完整自动投递通过。
