# 使用声明

本项目是**个人求职准备辅助工具**，不是招聘平台、不是代投服务，也不提供任何录用承诺。

## 允许的用途

- 整理本人简历、确认字段与段落，生成填写计划和送审单。
- 在本人操作下对照官网逐项填写；最终提交由本人点击。
- 本地运行、个人自用；代码可按 MIT 许可证使用与修改。

## 明确禁止

- 代登录、代填验证码、自动点击最终提交。
- 绕过验证码、风控、频率限制，或使用自动化批量爬取招聘网站。
- 代他人投递，或使用本项目伪造经历、证书、成绩、身份信息。
- 将本项目用于骚扰招聘方、批量刷投递或违反招聘网站条款的行为。

## Playwright / Chrome DevTools MCP（可选）

项目文档提供了接入 Playwright MCP、Chrome DevTools MCP 的**示例配置**，但：

- 产品**不内置、不默认开启**这些浏览器自动化服务。
- 是否接入由使用者自行决定并承担风险；需遵守目标网站的服务条款和频率限制。
- 即使接入，登录、验证码与最终提交仍应由本人完成；自动化只可用于读取页面结构、辅助定位字段和填入已确认文本。
- 网站页面结构变化、账号风险、封禁或数据错误由使用者自行承担。

## 数据与密钥

- 所有资料保存在访问者自己的浏览器；项目不提供云端存储。
- API Key 仅保存在本机，不进入资料/公司清单导出，也不写入日志。
- MCP 服务为本地 stdio 服务，无状态、不联网；传入的数据由调用方自行提供。
- AI 复核只返回提示，可能出错，不构成事实或录用判断；涉及身份、法律、薪资的字段由本人决定。

## 批量填写原则

遇到无法判断或与以往不同的字段时，先记录问题并继续完成其余部分，最后集中暂停由本人决定；不要为单个字段反复中断整个流程。
